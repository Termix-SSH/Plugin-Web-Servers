## Overview

Web Servers manages nginx, Apache and Caddy on your hosts over SSH. Each host gets its own tab for its sites, config files, logs and the server itself, and every change is tested before the server reloads.

Read the [docs](https://docs.termix.site/plugins/web-servers) to set it up and use it.

<br />

## Features

- See nginx, Apache and Caddy on a host with their version and state
- List every site with its domains, ports, HTTPS and certificate expiry
- Add static, reverse proxy, PHP and redirect sites from a form
- Edit any config file, with a test before every save and backups to go back to
- Turn sites on and off, start, stop, reload and restart the server
- Get a Let's Encrypt certificate for a site with certbot
- Read and follow access and error logs, with counts by status, path and client
- Install nginx, Apache, Caddy or certbot
- Get an alert when a web server stops
- A dashboard card, a panel beside the terminal and a Web Servers card in Host Metrics
- Reload, restart and test through Termix actions, with server state as a status tile

## Support

Bugs and ideas for Web Servers go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Web-Servers/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Web-Servers/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
